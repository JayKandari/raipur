# Raipur

A toy math calculator webapp. Plain HTML, CSS and JavaScript, no build step.

## Run locally

```bash
npm start
```

Open http://localhost:8000.

## Test

```bash
npm test
```

Runs the calculation engine unit tests with Node's built-in test runner (Node 18+).

## Deploy

Netlify serves the repo as static files: no build command. Push to the branch Netlify is connected to and it redeploys.
